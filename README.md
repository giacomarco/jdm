<a name="jdm_getAttribute"></a>

## jdm\_getAttribute(attribute) ⇒ <code>string</code> \| <code>null</code>
Restituisce il valore dell'attributo specificato per il nodo corrente.

**Kind**: global function  
**Returns**: <code>string</code> \| <code>null</code> - Il valore dell'attributo specificato oppure null se l'attributo non esiste.  

| Param | Type | Description |
| --- | --- | --- |
| attribute | <code>string</code> | Il nome dell'attributo di cui si vuole ottenere il valore. |
